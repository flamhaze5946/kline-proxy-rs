# 东京实例部署与性能对照（2026-09-17）

本报告主表是Rust 0.4.1的历史测量。之后已部署0.4.2并切换合约价格上游v2；新鲜度改善，但仍有长尾，详见[0.4.2部署与复测](ticker-v2-deployment-20260917.md)。原始主表保留。

Rust 0.4.1 已部署至 https://market-mirror.feng.dog（192.0.2.40），Java 仍为 https://market.feng.dog（192.0.2.30）。独立测试机：192.0.2.10。

## 结论

K 线和 bulk 的响应时间改善，进程内存观测值降低。独立复算确认主表数字，但单币价格存在上游版本与缓存行为的迁移差异；15.3秒长尾真实，低流量复测又出现21.1秒本机长尾。后台CPU未低于Java，当前结果不支持全部等价迁移、全面替换生产的结论。
